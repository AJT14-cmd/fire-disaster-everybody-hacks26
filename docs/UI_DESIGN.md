# UI Design Notes (Emergency-First)

## Design System

- Dark baseline theme for readability in smoke/night conditions.
- High contrast warning colors:
  - Critical: `#ff3b30`
  - Warning: `#ff9500`
  - Safe: `#34c759`
- Large tap targets for stressful conditions.
- Plain language labels and accessibility-friendly font sizing.

## Screen Layout Guide

- **Landing:** single CTA, concise mission text.
- **Dashboard:** risk card + emergency actions.
- **Live Map:** full-screen map + fixed legend panel.
- **Routing:** one-tap route compute + fallback alternatives.
- **Alerts:** prominent test/send button and feed area.
- **AI Chat:** quick prompts and compact answer card.
- **Contacts/Settings:** editable emergency profile and offline status.

## Animation Guidance

- Fire spread pulsing circles every 2-4 seconds.
- Route reroute banner slide-in when safer path appears.
- Alert cards shake once on high-severity notifications.
