# FirePath AI MVP Roadmap

## Phase 1 (Weeks 1-2): Foundation

- Set up Expo mobile app, Express backend, FastAPI AI service.
- Firebase Auth + Firestore integration.
- Basic user profile and emergency contacts.

## Phase 2 (Weeks 3-4): Intelligence + Map

- Integrate NASA FIRMS + OpenWeather + NOAA ingestion.
- Build live map overlays and risk color zones.
- Introduce WebSocket live updates.

## Phase 3 (Weeks 5-6): Routing + Alerts

- Implement risk-aware evacuation route scoring.
- Add Twilio SMS and push notifications.
- Build "I'm Safe" status broadcast.

## Phase 4 (Weeks 7-8): AI + Reliability

- Train wildfire risk model with confidence outputs.
- Add explainability and ETA spread estimation.
- Offline mode caching (map snapshot + route + contacts).

## Phase 5 (Weeks 9-10): Hardening

- Admin dashboard, rate limiting, encryption audit.
- Observability, incident runbooks, canary deploys.
- Accessibility and disaster UX stress testing.
